# 祭走 - SAISOU 3D Prototype

京都風の架空の古都を山車で走るブラウザ向け3D試作です。

## 起動方法
- `index.html` をローカルサーバー経由で開いてください（ES Modulesを使用するため、ファイルを直接開く方法は推奨しません）。
- 例：VS Code の Live Server、または `python -m http.server 8000`
- ブラウザで `http://localhost:8000` を開きます。
- Three.js と Rapier Physics は CDN から読み込みます。初回起動時はインターネット接続が必要です。

## 操作
- W / ↑：前進
- A / ←：左旋回
- D / →：右旋回
- S / ↓ / Space：ブレーキ
- C：カメラ切り替え（追尾 / 近距離 / 一人称風）
- 画面上のボタンでも視点切り替え・リセットが可能
- スマートフォンでは画面下部のタッチ操作を使用

## 現在の試作範囲
- Three.js による3D街並み・山車・閻魔の描画
- Rapier Physics による山車の剛体・慣性・旋回・衝突
- 建物との衝突判定
- 道を横断する歩行者NPC（接触時に減速・軽い衝撃）
- 路上の木箱・樽・籠などの障害物と回避走行
- 閻魔の追跡距離とゲームオーバー
- 追尾 / 近距離 / 一人称風カメラ
